# 🚗 PARKAPP

Proyecto académico desarrollado en Python como parte de un diplomado de grado universitario.

El objetivo principal fue construir una aplicación sencilla para gestionar y visualizar información relacionada con parqueaderos.

---

## 📌 Descripción

PARKAPP es una aplicación básica que permite modelar y gestionar datos de parqueaderos, incluyendo espacios disponibles y usuarios.

Este proyecto está enfocado en aplicar conceptos fundamentales de programación como:

* Estructuras de datos
* Modelado de entidades
* Lógica de negocio
* Organización de código

---

## 🧠 Objetivo del proyecto

El propósito de este proyecto no es ser un producto final, sino demostrar:

* Comprensión de lógica de programación
* Uso de Python en un caso práctico
* Diseño básico de una solución a un problema real

---

## ⚙️ Tecnologías utilizadas

* Python

---

## 🧩 Estructura del proyecto

El proyecto está organizado en módulos que representan las entidades principales del sistema, como:

* Parqueaderos
* Espacios
* Usuarios

Cada uno contiene la lógica necesaria para su gestión.

---

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/lasudev21/PARKAPP.git
```

2. Acceder al directorio:

```bash
cd PARKAPP
```

3. Ejecutar el archivo principal:

```bash
python main.py
```

---

## 🚧 Alcance

Este es un proyecto académico con funcionalidades básicas. No incluye:

* Interfaz gráfica avanzada
* Integraciones externas
* Persistencia compleja de datos
